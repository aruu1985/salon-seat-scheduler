# V0.12.13 稱謂代號

基於正式 main 7413bf8（V0.12.12），不合併候選分支。

姓名欄位仍儲存完整中文，例如「王小姐」、「王大學生」；按鈕 data-suffix 與 appendIdentity 使用中文值，identityLabel 與卡片 name 僅產生顯示文字。小姐與女士為不同值，共用 Ms. 顯示碼。成人顯示碼為 Ms.／Mr.／Kid／Mrs.；四個既有學生選項維持不變；大學生（大）位於高中生後。

既有完整姓名會以新碼顯示，但檢視、重讀不會寫回；原姓名本身含 J／S／T 或英文的紀錄保持原文，不猜測或批次轉換。只辨識結尾的完整中文稱謂，姓名中間文字不替換。詳細資料與編輯顯示原始完整姓名，服務項目、日期、座位與同步邏輯不變。

目前正式介面沒有獨立的客人姓名搜尋輸入框或查詢函式；沒有更改或新增搜尋流程。原始姓名不變，詳細資料仍可按完整姓名閱讀／瀏覽器文字搜尋；卡片的文字尋找則符合新的顯示代號。不能把這項檢查描述為測過不存在的姓名搜尋功能。

姓名與電話仍並排；稱謂按鈕改用表單整列寬度換行，避免手機照片中的半欄逐列堆疊。點擊與替換稱謂方式不變，沒有增加操作步驟。

不新增 Firestore 欄位、集合、索引或規則；不執行正式客人資料測試寫入。測試使用阻擋外網的合成 SDK，分別驗證單元規則、三種尺寸 Chromium／WebKit 表單、原始姓名及新預約儲存／編輯／重新讀取，與既有日期、固定休及承接提醒回歸。iPad Safari 實機仍待驗收。
