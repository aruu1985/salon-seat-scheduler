# V0.12.3 卡片排版與完整細項

## 變更

- 卡片文字在 DOM 實際渲染後，以內部容器的真實寬高及 Range 文字寬度量測，包含座位表縮放後的尺寸。移除先前以估算欄寬建立隱藏副本的字級計算。
- 姓名維持單行，優先在可讀範圍縮小以顯示完整簡碼姓名；姓名 10–18 CSS px、項目至少 9px、備註至少 9px、符號至少 8.5px。高度增加不會無限放大字體。
- 優先符號／姓名，再服務簡碼，再備註。服務可用一或兩行；備註依實際剩餘高度配置行數。沒有備註或關閉卡片備註時不產生空白備註行。短卡片共用緊湊橫列；極小縮放時維持可讀下限並裁切在卡片內，完整內容由細項查看，不為塞文字更改時間格或外框。
- 字體量測在 requestAnimationFrame 中合併縮放／ResizeObserver 更新。所有裝置共用同一套 `card-layout.js`，不以裝置類型另寫規則。
- 點卡片仍開原操作視窗，上方新增唯讀完整資料：原始姓名、電話（有值）、日期、起訖、座位、主檔中的設計師編號／名稱、原始服務名稱、額外指定人員（有值）、完整備註（有值）及第二服務類型／項目／人員／日期／起訖／備註。
- 細項直接使用既有 appts 與人員主檔。未新增資料欄位、資料副本或資料查詢；純查看不觸發 Firestore 寫入。未知人員維持原有代號，不硬編碼姓名。
- 細項可獨立捲動，編輯／刪除／關閉按鈕維持在固定底部區域。保留刪除警告、密碼及多次確認、垃圾桶與紀錄流程；背景快照會更新細項並保留捲動位置，已刪除或切換日期時停用該筆操作。
- 備註編輯框改為同 ID 的 textarea，避免進入編輯時原生單行 input 移除既有換行。仍使用原有 name/note/secondaryService 等欄位與儲存路徑。

沒有改動座位欄寬、時間格高度、卡片高度／起訖座標、服務時長、`occupiedSlots`、`calculateBlockHeight`、`canPlace`、`timeConflict` 或 `seat-layout.js`。設計師顏色、△ 指定邏輯、服務簡碼、第二服務排程均沿用。

## 測試與界線

`tests/card-view.py` 在 Chromium 與 Playwright WebKit 26.5 引擎，分別以 390×844、820×1180、1440×1000 執行：

| 驗收 | 結果 |
|---|---|
| 兩字、三字、四字及較長姓名 | 通過；一般 1 小時以上卡片在 100%／59% 顯示完整常見姓名；過長姓名只在可讀下限仍放不下時省略 |
| 30／60／120／240 分鐘 | 通過；實際外框高度等於既有 1／2／4／8 格扣內縮 |
| 備註開關與空內容 | 通過；開啟時納入排版，關閉時不留空白；細項不受卡片顯示開關限制 |
| 多項服務、色彩、指定符號 | 通過；服務簡碼／各設計師既有顏色保留 |
| 實際卡片尺寸與縮放 | 通過；100%／59% 以相同程式量測，不更改整張表的縮放值 |
| 唯讀完整細項 | 通過；完整原始姓名、服務、長備註、電話、日期時間、座位、人員與第二服務可直接閱讀，內容非表單控件 |
| 長內容與固定按鈕 | 通過；細項可捲至底部，三個按鈕保持在視窗內 |
| 無電話／無備註 | 通過；不顯示空欄位 |
| 編輯／儲存／關閉 | 通過；回到完整原始輸入，備註保留換行，使用者明確儲存後細項更新 |
| 刪除確認／垃圾桶 | 通過；取消零寫入；完整四階段確認後在隔離 mock 移至垃圾桶並移除卡片 |
| 點空白時間格新增 | 通過；沿用原雙擊事件進入新增表單 |
| 純查看與重新排版 | 通過；mock 原始文件字串逐一比對完全相同、沒有任何寫入 |

額外執行 `tests/formatting.py`、`browser.py`、`interaction.py`、`overlap.py`、`update.py`、`sync.py` 及既有節點單元測試。極小適合畫面縮放下，測試文字始終由內部容器裁切，不會遮住其他預約；不以降低到不可讀字級來滿足不可能的多行高度。

測試均攔截外部 Firebase 請求，使用記憶體 SDK mock；`tests/mock-admin.js` 只為測試補足既有刪除、垃圾桶、稽核所需 API，沒有對正式資料操作。正式驗證僅核對 GitHub Pages workflow、正式入口、版本 JSON 與全部發布資源。

WebKit 是自動化瀏覽器引擎測試，不是 iPhone／iPad Safari 實機測試；本次未操作實際 Apple 裝置，不宣稱實機通過。

命令：

```
python tests/card-view.py
SALON_TEST_ENGINE=webkit python tests/card-view.py
node tests/appointment-details.cjs
```

WebKit 需先安裝相容 Playwright browser 及其執行依賴。本次 browser 與補充 WPE libraries 放在 /tmp，沒有更動專案依賴或系統套件。
