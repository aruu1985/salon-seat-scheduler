# V0.12.10 日期選擇流程

從正式 V0.12.9（afdda5f）獨立開發；未合併同行、Spark、到店或備份分支。

原本主畫面使用瀏覽器原生 `input[type=date]`；網頁無法取得原生年月／月曆子畫面或攔截原生藍色打勾。現在僅將主畫面的互動改為共用 HTML dialog；原 `dateInput`、YYYY-MM-DD 值、前一天／今天／明天、change 事件、Firestore 讀取與儲存流程維持原樣。其他表單的日期欄位不變。

## 操作

- 開啟先顯示原選取日期的月曆，點月曆上方的年月可切到年月滾輪。
- 年月滾輪可觸控捲動、滑鼠滾動、點選與方向鍵／PageUp／PageDown；中央選取列與文字草稿同步。年份以移動視窗延伸，不限於今年或手動年表。
- 年月畫面的右下藍勾只回到選定年月的月曆，不關閉、不觸發 input/change、不查詢資料。
- 月曆選日後的藍勾才套用 YYYY-MM-DD，關閉並觸發既有 change 流程一次。未改日期時不重複觸發查詢。
- 取消、Escape 與外側背景點擊均捨棄草稿。重置回到本次開啟時的日期，保持目前子畫面，仍須在月曆打勾才套用。
- 前後月保留偏好的日數；31 日切到二月暫用該月最後一天，未另外選日時切回三月仍是 31 日。另選日期後以新日數為準。
- 閏年採西曆規則，跨年依年月計算；以 UTC 計算星期以避免裝置時區影響格位，不轉換儲存日期。
- 使用原生 dialog 焦點隔離與取消事件；月曆方向鍵可換日，PageUp／PageDown 換月。按鈕留在底部，中間可捲動。既有版本更新機制識別 dialog[open]，不會在未關閉時更新。
