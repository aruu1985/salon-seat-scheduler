## 共用對照

`appointment-format.js` 是表單標籤與卡片的唯一對照來源，不用於儲存資料。

| 完整稱謂或身分（僅比對姓名結尾） | 卡片代號 |
|---|---|
| 先生 | S |
| 小姐、女士 | J |
| 太太 | T |
| 幼稚園、幼兒園 | 幼 |
| 國中、國中生 | 國 |
| 高中、高中生 | 高 |
| 小孩 | 小孩（沿用舊行為，未自訂新代號） |

快捷按鈕沿用原本「小姐、先生、小孩」，加入女士、太太、幼稚園、國中生、高中生。點擊會替換姓名末尾原有的完整稱謂／身分，同一按鈕重複點擊不重複附加；不處理姓名中間的文字，也不把 S/J 等單字母當成可刪除的原始稱謂。儲存仍為「王小弟幼稚園」等完整姓名。

| 原始消費項目 | 卡片代號 |
|---|---|
| S洗 | S洗（保留既有辨識） |
| 洗髮、洗 | 洗 |
| 剪髮、K剪、剪 | 剪 |
| 洗剪 | 洗剪 |
| 燙髮、燙 | 燙 |
| 染髮、染 | 染 |
| 補染 | 補 |
| 護髮、護 | 護 |
| 頭皮 | 頭 |
| 造型、單造型 | 型 |
| 美甲 | 甲 |
| 其他自訂／歷史項目 | 保留完整名稱 |

已知選項的表單標籤使用「原名（代號）」，checkbox 的 value 仍是原名。不同原始項目即使顯示代號相同也不合併（如 K剪、剪髮）；多選使用全形「＋」，略過空項目，未知名稱不拆字猜測。

## 排版與資料安全

只修改卡片字串、行內排版與測量字級；姓名與服務優先維持單行。極長文字保留完整 DOM/title 與編輯值，視覺上以省略號避免溢出；短卡片以實際高度計算能容納核心資訊的字級，額外資訊沿用既有固定高度裁切。沒有改動 `occupiedSlots`、`calculateBlockHeight`、`canPlace`、`timeConflict`、`seat-layout.js`、座位資料、開始時間或服務時長。沿用 SalonStaff 顏色與 assignmentMarkers 的 △ 邏輯。

舊預約的歷史項目即使已不在當前 catalog，也會在原多選框保留完整已勾選選項，避免編輯時遺漏原始項目。沒有新增資料欄位、資料遷移或批次改寫。
